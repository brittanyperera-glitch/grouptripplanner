# Guide: phrases (checked by Brittany 2026-10-15; packing list cut)

## Phrases (Sinhala, written in English letters, with how to say it)

| English | Sinhala | Say it like |
|---|---|---|
| Hello / welcome (formal greeting) | Ayubowan | AH-yu-bo-wan |
| Thank you | Istuti | ISS-too-tee |
| Thank you very much | Bohoma istuti | BO-ho-ma ISS-too-tee |
| How are you? | Kohomada? | KO-ho-ma-da |
| I'm good | Hondai | HON-dye |
| Yes | Ow | aoh |
| No | Naha | NAA-ha |
| Uncle (what you call any older man, the tuk-tuk driver included) | Uncle / Mama | AN-kul / MAA-maa |
| Aunty (any older woman) | Aunty / Nenda | AAN-tee / NEN-da |
| Big brother / big sister (friendly, for someone a bit older) | Aiya / Akka | AI-ya / AK-ka |
| One beer | Beer ekak | BEER eh-kak |
| Let's go | Yamu | Yah-mooh |
| Let's eat | Kamu | kuh-mooh |
| Let's drink | Bomu | boh-mooh |
| How much? | Kiyada? | key-yuh-the |
| Too expensive! | Ganan wadi! | GA-nan WA-dee |
| Delicious | Rasai | RA-sigh |
| Very spicy | Hari sarai | HA-ree SA-rye |
| No problem / it's fine | Kamak naha | KA-mak NAA-ha |
| Wow / cool | Maru | MA-roo |
